# AbsensiQR Pro - Product Overview

**AbsensiQR Pro** is a comprehensive school attendance management system using QR Code technology with multi-tenant support for Indonesian schools (SD/SMP/SMA/SMK).

## Core Features

- **QR Code Attendance**: Dynamic QR generation per session with GPS validation
- **Multi-Tenant Architecture**: Support for multiple schools with isolated data
- **9-Role System**: Super Admin, School Admin, Principal, Vice Principal, Teacher, Homeroom Teacher, Staff, Student, Parent
- **Real-time Updates**: WebSocket integration for live attendance feeds
- **Mobile Support**: React Native app for students and teachers
- **Payment Integration**: Midtrans payment gateway for subscription packages
- **WhatsApp Notifications**: Automated parent notifications
- **Comprehensive Reporting**: Daily/weekly/monthly reports with PDF/Excel export

## Target Users

- **Schools**: SD, SMP, SMA, SMK across Indonesia
- **Teachers**: QR scanning, manual attendance input, class management
- **Students**: Mobile app for attendance scanning
- **Parents**: Attendance monitoring and notifications
- **Administrators**: School management and reporting

## Business Model

Subscription-based SaaS with three tiers:
- **Basic**: Small schools (up to 100 students)
- **Standard**: Medium schools (up to 500 students)  
- **Premium**: Large schools (unlimited students)

## Key Differentiators

- GPS location verification for attendance integrity
- Multi-language support (Indonesian focus)
- Offline capability for mobile apps
- Comprehensive audit trail with device tracking
- Role-based access control with granular permissions
